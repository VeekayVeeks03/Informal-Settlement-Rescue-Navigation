# GitHub Upload Steps - Navigation

Open Command Prompt inside this folder and run:

```bash
git init
git add .
git commit -m "Add informal settlement rescue navigation project"
git branch -M main
git remote add origin https://github.com/VeekayVeeks03/Informal-Settlement-Rescue-Navigation.git
git push -u origin main
```

If your GitHub repo has a different name, replace the remote URL before pushing.
